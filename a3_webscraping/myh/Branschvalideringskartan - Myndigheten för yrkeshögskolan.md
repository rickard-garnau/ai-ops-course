# Branschvalideringskartan

Den här kartan är till för dig som vill veta vilka branschvalideringsmodeller som är tillgängliga i olika delar av landet.

## Så fungerar kartan

Du kan klicka på ett geografiskt område i kartbilden för att se vilka yrken som kan valideras genom branschvalideringsmodeller inom den regionen. Om du istället vill utgå från enskilda yrken eller valideringsmodeller kan du klicka i listorna för att få information om var de kan valideras. Har du markerat ett sådant val kan du också gå vidare till ansvarig organisations hemsida genom länken som visas.

Behöver du veta om en branschvalideringsmodell är upphandlad av Arbetsförmedlingen kan du se det via länken nederst.
