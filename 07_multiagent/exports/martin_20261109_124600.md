Hi Martin! To become a data engineer while learning Python:

Study path: Master Python fundamentals, then Pandas for data manipulation. Learn SQL deeply (joins, aggregations). Build ETL pipelines: extract from APIs, transform with Python/SQL, load into databases. Use Git, Docker, and one cloud platform (AWS/Azure/GCP). Learn Airflow for orchestration and dbt for transformation. Build 2-3 end-to-end portfolio projects on GitHub.

Career path: Target Junior Data Engineer, Analytics Engineer, or ETL Developer roles. Get one cloud certification (AWS, Azure, or GCP). Optimize LinkedIn, network with data engineers, and apply to mid-size companies. Expect 6-12 months part-time.

Start with one small end-to-end project and share it on GitHub. Consistency is key!
